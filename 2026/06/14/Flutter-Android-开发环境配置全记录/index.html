Flutter Android 开发环境配置全记录

本文记录了从零开始配置 Flutter Android 开发环境的完整过程，包含踩过的坑和对应解决方案。适合有编程基础（Python / JS / Vue）但没有移动端经验的开发者参考。

系统环境：Windows，所有工具安装在 F 盘。

整体思路

Flutter Android 开发涉及 4 套独立的网络下载，国内都需要配置镜像才能正常使用：

下载内容 镜像方案
Flutter SDK 本体 FLUTTER_STORAGE_BASE_URL 环境变量
Pub 第三方依赖包 PUB_HOSTED_URL 环境变量
Gradle 依赖库（Maven） init.gradle 全局配置
Gradle 本体 ZIP gradle-wrapper.properties 替换下载源

⚠️ 重要：先配镜像，再安装工具，否则下载会超时或极慢。

默认情况下 Android Studio 相关工具会占用 C 盘 10GB 以上，建议全部安装到其他盘：

内容 默认位置 占用大小
Android Studio IDE C:\Program Files ~1.5 GB
Android SDK C:\Users\用户名\AppData\Local\Android ~3–5 GB
AVD 模拟器镜像 C:\Users\用户名.android\avd ~3–8 GB
Gradle 缓存 C:\Users\用户名.gradle ~1–3 GB

在 F 盘提前建好统一的目录结构，便于后续管理：

路径中不能含有中文和空格，否则部分工具会报路径解析错误。

第二步：配置系统环境变量

打开方式：控制面板 → 系统 → 高级系统设置 → 环境变量 → 系统变量

新建以下 4 条变量

变量名 变量值 作用
FLUTTER_STORAGE_BASE_URL https://storage.flutter-io.cn Flutter SDK 下载镜像
PUB_HOSTED_URL https://pub.flutter-io.cn Pub 包管理镜像
ANDROID_AVD_HOME F:\Android\AVD 模拟器存储路径
GRADLE_USER_HOME F:\Android\Gradle Gradle 缓存路径

❌ 问题：flutter doctor --android-licenses 报错 sdkmanager not found

报错信息：

原因： Android SDK Command-line Tools 没有安装，flutter doctor --android-licenses 依赖该工具。

解决方案：

  1. 打开 Android Studio
  2. Settings → Languages & Frameworks → Android SDK → 点击 SDK Tools 标签
  3. 勾选 Android SDK Command-line Tools (latest)
  4. 点击 OK，等待下载完成
